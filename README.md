# Gamma Knife — прогнозирование интракраниальной прогрессии

Прогнозирование интракраниальной прогрессии у пациентов после радиохирургии на аппарате «Гамма-нож» методами машинного обучения. Бинарная классификация; выборка — 583 пациента, выраженный дисбаланс классов.

Проект вёлся в двух треках: **интерпретируемая модель для научной статьи** и **соревновательный ансамбль на Kaggle**.

## Данные и признаки
- Очистка и предобработка, `log1p`-преобразования скошенных признаков, обработка аномалий и выбросов.
- Генерация признаков: объём на очаг, индекс опухолевой нагрузки и др.
- Нативная работа с категориальными признаками в CatBoost.
- Балансировка классов через `scale_pos_weight`.

## Модель для статьи (интерпретируемая)
- CatBoost + SHAP-анализ (на уровне всей выборки и отдельных пациентов).
- Сравнение с логистической регрессией и деревом решений (а также LightGBM/XGBoost).
- 5-fold стратифицированная кросс-валидация, OOF-предсказания, подбор порога классификации.
- **Метрики:** ROC-AUC = 0.810, PR-AUC = 0.901, balanced accuracy = 0.739, recall = 0.587.

## Соревновательный трек (Kaggle)
- Более сложный ансамбль моделей (без SHAP-интерпретации) для максимизации метрики.
- Вероятностный блендинг: LightGBM 0.84 / XGBoost 0.12 / CatBoost 0.04.
- **Результат:** balanced accuracy ≈ 88.64%.

## Статья
Соавтор научной статьи «Прогнозирование интракраниальной прогрессии после радиохирургии на аппарате „Гамма-нож“ с использованием методов машинного обучения».
